# Sentry CLI

## Overview

A skill for using Sentry CLI and API for error tracking, release management, source map uploads, and performance monitoring configuration. Enables automated error monitoring workflows and integration with CI/CD pipelines.

## When to Use

- Managing Sentry releases and commits from CLI
- Uploading source maps for readable stack traces
- Configuring error tracking and performance monitoring
- Automating Sentry project configuration
- Integrating Sentry into deployment pipelines

## Workflow

### Step 1: Project Setup
Configure Sentry project with DSN, organization, and project settings.

### Step 2: Release Management
Create releases, associate commits, and manage release lifecycle.

### Step 3: Source Map Upload
Upload source maps for production error debugging.

### Step 4: Monitoring Configuration
Configure performance monitoring, alerts, and integration with CI/CD.
