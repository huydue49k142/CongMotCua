# Knowledge Catalog Discovery

## Overview

A skill for building AI agents that automatically catalog, index, and enable discovery of knowledge assets across repositories, wikis, databases, and document stores. Facilitates enterprise knowledge management and semantic search.

## When to Use

- Building an enterprise knowledge management system
- Enabling semantic search across organizational knowledge bases
- Automating knowledge asset cataloging and metadata extraction
- Creating intelligent discovery interfaces for knowledge workers
- Implementing knowledge graph connections between related assets

## Workflow

### Step 1: Source Connection
Connect to knowledge sources including wikis, document stores, code repositories, and databases.

### Step 2: Asset Ingestion
Ingest assets with automatic metadata extraction, categorization, and indexing.

### Step 3: Relationship Mapping
Map relationships between knowledge assets to create a connected knowledge graph.

### Step 4: Discovery Interface
Provide a discovery interface with semantic search, recommendations, and browsing.
