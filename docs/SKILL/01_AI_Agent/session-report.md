# Session Report

## Overview

A skill for generating comprehensive session reports from AI agent interactions. Captures task context, decisions made, outcomes achieved, and lessons learned for documentation and knowledge retention.

## When to Use

- Documenting AI agent session outcomes and key decisions
- Generating structured reports for project stakeholders
- Capturing context and rationale for technical decisions
- Creating knowledge artifacts from agent-assisted work
- Tracking progress and achievements across sessions

## Workflow

### Step 1: Session Context
Capture session goals, tasks attempted, and initial context.

### Step 2: Activity Logging
Record key actions, decisions, code changes, and outcomes during the session.

### Step 3: Report Generation
Compile a structured report with summaries, achievements, challenges, and next steps.

### Step 4: Knowledge Preservation
Save the report for future reference and team knowledge sharing.
