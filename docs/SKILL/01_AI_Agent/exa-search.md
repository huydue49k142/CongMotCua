# Exa Search

## Overview

A skill for leveraging Exa's neural search API to perform deep web research with an AI agent. Enables semantic search across the web, content extraction, and intelligent information synthesis for research-intensive tasks.

## When to Use

- Performing deep web research with semantic understanding
- Finding relevant content by meaning rather than just keywords
- Extracting structured data from web pages at scale
- Building research pipelines for content analysis
- Gathering competitive intelligence and market research

## Workflow

### Step 1: Define Research Query
Formulate the research question with semantic context and desired information types.

### Step 2: Execute Neural Search
Use Exa's semantic search to find the most relevant web content matching the query intent.

### Step 3: Extract & Analyze
Extract content from matched pages and analyze for relevant information.

### Step 4: Synthesize Results
Synthesize findings into structured summaries with citations and source references.
