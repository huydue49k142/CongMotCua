# Linear SDK Scripting

## Overview

A skill for automating Linear project management workflows using the Linear SDK. Enables programmatic issue creation, sprint management, team analytics, and custom workflow automations.

## When to Use

- Automating issue creation and management in Linear
- Building custom sprint planning and tracking tools
- Generating team analytics and productivity reports
- Creating automated workflow integrations with Linear
- Implementing bulk operations and migration scripts

## Workflow

### Step 1: Authentication Setup
Configure Linear API authentication with personal API keys or OAuth tokens.

### Step 2: Define Automation
Design the automation workflow including issue lifecycle, team operations, and reporting needs.

### Step 3: Implementation
Implement the script using Linear SDK with proper error handling and rate limiting.

### Step 4: Testing & Deployment
Test the automation with sample data and deploy as scheduled tasks or integrations.
