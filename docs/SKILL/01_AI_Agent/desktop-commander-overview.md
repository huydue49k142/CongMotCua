# Desktop Commander Overview

## Overview

A skill for AI agents to interact with desktop environments, execute local commands, manage files, and control system resources. Enables agents to perform local operations, automate desktop tasks, and manage development environments.

## When to Use

- Automating local development workflows and tasks
- Managing files, directories, and project structures
- Executing system commands and scripts programmatically
- Monitoring system resources and processes
- Performing local testing and debugging operations

## Workflow

### Step 1: Define Task
Identify the desktop operation or command sequence needed to accomplish the goal.

### Step 2: Execute Command
Run the appropriate system commands with proper error handling and output capture.

### Step 3: Process Results
Analyze command output, handle errors, and extract relevant information.

### Step 4: Report & Cleanup
Present results and perform any necessary cleanup operations.
