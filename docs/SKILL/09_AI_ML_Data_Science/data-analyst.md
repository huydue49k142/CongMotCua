# Data Analyst

## Overview

A skill for performing comprehensive data analysis using AI agents. Covers data cleaning, exploratory analysis, statistical modeling, visualization creation, and insight generation for data-driven decision making.

## When to Use

- Performing exploratory data analysis on structured datasets
- Generating data visualizations and dashboards
- Conducting statistical analysis and hypothesis testing
- Creating automated data analysis pipelines
- Generating business intelligence reports and insights

## Workflow

### Step 1: Data Ingestion
Load and validate data from various sources including CSV, databases, APIs, and data warehouses.

### Step 2: Data Cleaning & Preparation
Clean data by handling missing values, outliers, and inconsistencies.

### Step 3: Analysis & Modeling
Perform statistical analysis, build models, and identify patterns and trends.

### Step 4: Visualization & Reporting
Create visualizations and generate comprehensive analysis reports with actionable insights.
