# Web Design Guidelines

## Overview

A comprehensive skill covering modern web design principles and guidelines. Covers visual hierarchy, typography, color theory, layout patterns, responsive design, accessibility, and user experience best practices for creating professional web interfaces.

## When to Use

- Designing web interfaces with modern UI/UX principles
- Creating accessible and responsive web layouts
- Establishing design systems and component libraries
- Improving visual design quality and consistency
- Following best practices for web typography and color

## Workflow

### Step 1: Design Planning
Define design objectives, target audience, and brand guidelines.

### Step 2: Visual Design
Apply design principles including hierarchy, color theory, typography, and spacing.

### Step 3: Responsive Implementation
Design for multiple screen sizes with responsive breakpoints and fluid layouts.

### Step 4: Accessibility & Testing
Ensure WCAG compliance, test usability, and iterate based on feedback.
