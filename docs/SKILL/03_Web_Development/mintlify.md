# Mintlify

## Overview

A skill for creating and maintaining documentation sites with Mintlify. Covers site configuration, content organization, API documentation, and integration with AI-powered writing assistance for developer-friendly documentation.

## When to Use

- Building modern documentation sites for APIs and products
- Creating developer portals with interactive API references
- Organizing documentation with Mintlify's content structure
- Maintaining and updating documentation with AI assistance
- Migrating existing documentation to Mintlify

## Workflow

### Step 1: Site Configuration
Set up Mintlify project with navigation structure, theme, and custom domain configuration.

### Step 2: Content Creation
Write and organize documentation pages with proper formatting, code snippets, and images.

### Step 3: API Documentation
Generate interactive API references from OpenAPI specs with try-it-out functionality.

### Step 4: Deployment & Maintenance
Deploy to production, set up analytics, and establish content update workflows.
