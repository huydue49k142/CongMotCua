# Searching Sourcegraph

## Overview

A skill for leveraging Sourcegraph's code search and intelligence capabilities. Covers advanced search queries, code navigation, batch changes, and integration with development workflows for large-scale codebase exploration.

## When to Use

- Searching across large codebases with complex queries
- Understanding code dependencies and usage patterns
- Finding code patterns, anti-patterns, and security issues
- Performing codebase-wide refactoring analysis
- Onboarding to new codebases with code intelligence

## Workflow

### Step 1: Define Search Query
Construct search queries using Sourcegraph's search syntax with filters for language, repo, and patterns.

### Step 2: Execute Search
Run searches across repositories and analyze results with code intelligence.

### Step 3: Navigate & Explore
Use code navigation features for definitions, references, and dependency traversal.

### Step 4: Batch Operations
Use batch changes for codebase-wide changes and large-scale refactoring.
