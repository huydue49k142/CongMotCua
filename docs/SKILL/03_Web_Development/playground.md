# Playground

## Overview

A skill for creating and managing interactive code playgrounds for rapid prototyping, experimentation, and learning. Provides a sandboxed environment for testing code snippets, exploring APIs, and iterating on ideas quickly.

## When to Use

- Rapidly prototyping new features or algorithms
- Testing code snippets in an isolated environment
- Experimenting with new libraries or frameworks
- Creating interactive learning and demonstration environments
- Debugging and reproducing issues in isolation

## Workflow

### Step 1: Define Experiment
Identify the concept, algorithm, or feature to prototype.

### Step 2: Setup Environment
Configure the playground with necessary dependencies and test data.

### Step 3: Implement & Test
Write and iterate on the code, testing assumptions and edge cases.

### Step 4: Document & Export
Document findings, export working solutions, and clean up the playground.
