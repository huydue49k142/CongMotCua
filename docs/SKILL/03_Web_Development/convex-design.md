# Convex Design

## Overview

A skill for designing and building full-stack applications with Convex as the reactive backend platform. Covers schema design, query patterns, real-time subscriptions, and integration with frontend frameworks.

## When to Use

- Building full-stack applications with Convex backend
- Designing reactive data flows with real-time subscriptions
- Implementing authentication and authorization in Convex
- Optimizing Convex queries and mutations for performance
- Migrating from traditional backend to Convex architecture

## Workflow

### Step 1: Schema Design
Design Convex schema with tables, indexes, and relationships based on application requirements.

### Step 2: Backend Logic
Implement queries, mutations, and actions with proper access control and validation.

### Step 3: Frontend Integration
Connect frontend framework to Convex with reactive data subscriptions.

### Step 4: Deployment & Monitoring
Deploy the application and monitor performance with Convex dashboard and logging.
