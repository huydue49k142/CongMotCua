# Site Specification

## Overview

A skill for creating detailed website specifications that guide development. Covers information architecture, content strategy, technical requirements, design specifications, and user experience planning.

## When to Use

- Planning new website projects with detailed specifications
- Defining technical and functional requirements for web projects
- Creating information architecture and sitemaps
- Specifying design systems and component libraries
- Documenting technical constraints and performance requirements

## Workflow

### Step 1: Requirements Gathering
Collect business objectives, target audience, and functional requirements.

### Step 2: Information Architecture
Design sitemap, navigation structure, and content organization.

### Step 3: Technical Specification
Define tech stack, performance budgets, accessibility requirements, and integration points.

### Step 4: Design Specification
Specify design system, responsive breakpoints, and interaction patterns.
