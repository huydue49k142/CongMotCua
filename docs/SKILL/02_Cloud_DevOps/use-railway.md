# Use Railway

## Overview

A skill for deploying and managing applications on the Railway platform. Covers service configuration, environment management, database provisioning, custom domains, and scaling strategies for full-stack applications.

## When to Use

- Deploying web applications and APIs on Railway
- Configuring services, databases, and environment variables
- Managing Railway deployments with GitHub integration
- Setting up custom domains and SSL certificates
- Scaling applications with Railway's infrastructure

## Workflow

### Step 1: Project Setup
Connect repository to Railway and configure service settings.

### Step 2: Environment Configuration
Set up environment variables, secrets, and service connections.

### Step 3: Database & Add-ons
Provision databases and additional services required by the application.

### Step 4: Deployment & Monitoring
Deploy the application, configure custom domains, and monitor performance.
