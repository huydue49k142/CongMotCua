# TeamCity CLI

## Overview

A skill for managing TeamCity CI/CD servers through CLI tools and automation. Covers build configuration management, trigger setup, artifact handling, and integration with version control systems.

## When to Use

- Managing TeamCity build configurations programmatically
- Automating build triggers and CI/CD pipeline setup
- Configuring build steps, artifacts, and dependencies
- Integrating TeamCity with version control and deployment tools
- Monitoring build status and managing build agents

## Workflow

### Step 1: Project Setup
Create TeamCity project and configure VCS roots for source control integration.

### Step 2: Build Configuration
Define build steps, triggers, dependencies, and artifact rules.

### Step 3: Automation & Integration
Set up automated triggers, parameterized builds, and deployment pipelines.

### Step 4: Monitoring & Maintenance
Monitor build health, manage agents, and maintain build configurations.
