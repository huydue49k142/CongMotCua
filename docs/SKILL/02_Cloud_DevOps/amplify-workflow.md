# Amplify Workflow

## Overview

A skill for managing AWS Amplify workflows including full-stack application deployment, CI/CD pipeline configuration, branch-based environments, and hosting management. Enables streamlined development-to-production workflows.

## When to Use

- Setting up CI/CD for Amplify-hosted web applications
- Managing branch-based deployment environments
- Configuring build settings and custom domains
- Implementing preview deployments for pull requests
- Automating Amplify environment management

## Workflow

### Step 1: Application Setup
Configure Amplify app with repository connection and branch settings.

### Step 2: Build Configuration
Define build settings, environment variables, and framework-specific configurations.

### Step 3: Environment Management
Set up branch-based environments with backend and frontend deployment.

### Step 4: Domain & Monitoring
Configure custom domains, SSL certificates, and deployment monitoring.
