# Dataproc Skills

## Overview

A skill for managing Google Cloud Dataproc clusters, running Spark/Hadoop jobs, and optimizing big data processing workflows. Covers cluster provisioning, autoscaling, job scheduling, and cost optimization.

## When to Use

- Provisioning and managing Dataproc clusters for big data processing
- Running Spark, Hadoop, or Hive jobs on Google Cloud
- Optimizing Dataproc cluster performance and cost
- Implementing autoscaling and workload-optimized clusters
- Migrating on-premise Hadoop workloads to Dataproc

## Workflow

### Step 1: Cluster Design
Design cluster configuration based on workload requirements, including machine types and optional components.

### Step 2: Job Configuration
Configure and submit Spark/Hadoop jobs with appropriate resource allocation.

### Step 3: Monitoring & Optimization
Monitor cluster performance, adjust autoscaling, and optimize resource utilization.

### Step 4: Cleanup & Cost Management
Implement cluster auto-deletion and cost tracking for ephemeral workloads.
