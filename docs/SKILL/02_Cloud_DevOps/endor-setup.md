# Endor Setup

## Overview

A skill for setting up and configuring Endor Labs for software supply chain security. Covers dependency analysis, policy creation, vulnerability scanning, and integration with CI/CD pipelines for automated security gate enforcement.

## When to Use

- Setting up software supply chain security with Endor Labs
- Analyzing dependency trees for security vulnerabilities
- Creating and enforcing security policies for open-source dependencies
- Integrating Endor Labs into CI/CD pipelines
- Monitoring and remediating dependency risks

## Workflow

### Step 1: Account & Agent Setup
Create Endor Labs account, install CLI, and configure authentication.

### Step 2: Project Onboarding
Onboard projects for dependency scanning with proper configuration files.

### Step 3: Policy Configuration
Define security policies for vulnerability severity, license compliance, and dependency freshness.

### Step 4: CI/CD Integration
Integrate Endor Labs scanning into CI/CD pipelines with automated policy enforcement.
