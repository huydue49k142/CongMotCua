# Webapp Testing

## Overview

A comprehensive skill for testing web applications across all layers. Covers testing strategy design, unit testing, integration testing, end-to-end testing, visual regression testing, and test automation best practices for modern web applications.

## When to Use

- Designing a comprehensive web application testing strategy
- Implementing unit and integration tests for frontend/backend
- Setting up end-to-end testing with CI/CD integration
- Adding visual regression testing for UI components
- Improving test coverage and reliability

## Workflow

### Step 1: Test Strategy
Define testing pyramid, coverage goals, and tool selection for the application.

### Step 2: Unit & Integration Tests
Implement unit tests for business logic and integration tests for component interactions.

### Step 3: E2E & Visual Tests
Write end-to-end user flow tests and visual regression tests for UI components.

### Step 4: CI Integration & Monitoring
Integrate tests into CI/CD pipeline and set up test monitoring and reporting.
