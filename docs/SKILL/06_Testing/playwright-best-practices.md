# Playwright Best Practices

## Overview

A comprehensive skill covering Playwright testing best practices for reliable, maintainable end-to-end tests. Covers test design patterns, selectors strategy, parallel execution, debugging, and CI/CD integration.

## When to Use

- Writing reliable and maintainable Playwright tests
- Designing page object models and test fixtures
- Implementing parallel test execution strategies
- Debugging flaky tests and improving test stability
- Integrating Playwright tests into CI/CD pipelines

## Workflow

### Step 1: Test Strategy
Define test scope, page objects, and fixture structure for the application.

### Step 2: Test Implementation
Write tests with proper locators, assertions, and data management patterns.

### Step 3: Execution & Debugging
Run tests with parallel workers, handle flakiness, and use debugging tools.

### Step 4: CI Integration
Configure CI/CD pipeline for Playwright with reporting and artifact collection.
