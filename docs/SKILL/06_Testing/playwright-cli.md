# Playwright CLI

## Overview

A skill for using Playwright's CLI tools for browser automation, debugging, code generation, and test execution. Covers CLI commands for recording tests, running in different browsers, generating screenshots, and troubleshooting.

## When to Use

- Generating test code with Playwright's codegen tool
- Running Playwright tests from the command line
- Debugging tests with trace viewer and inspector
- Capturing screenshots and recording videos
- Managing browser installations and configurations

## Workflow

### Step 1: Environment Setup
Install Playwright and required browsers using CLI commands.

### Step 2: Test Generation
Use Playwright codegen to record and generate test scripts.

### Step 3: Test Execution
Run tests across browsers with configuration options and reporters.

### Step 4: Debugging & Reporting
Use trace viewer, HTML reports, and screenshots for test analysis.
