# Spanner Data

## Overview

A skill for designing and managing Google Cloud Spanner databases. Covers schema design for globally distributed SQL, interleaved tables, secondary indexes, query optimization, and transaction management for horizontally scalable relational databases.

## When to Use

- Designing schemas for globally distributed relational databases
- Implementing strong consistency across regions with Spanner
- Optimizing Spanner query performance and reducing latency
- Managing schema changes and migrations in Spanner
- Building scalable OLTP applications with Spanner

## Workflow

### Step 1: Schema Design
Design Spanner schema with interleaved tables, primary keys, and indexing strategy.

### Step 2: Query Optimization
Optimize queries using secondary indexes, query distribution analysis, and best practices.

### Step 3: Transaction Design
Implement transactions with appropriate isolation levels and handle contention.

### Step 4: Operations & Monitoring
Manage schema migrations, monitor performance, and plan capacity.
