# OracleDB

## Overview

A comprehensive skill for working with Oracle databases. Covers SQL optimization, PL/SQL development, database administration, performance tuning, and high-availability configurations for enterprise environments.

## When to Use

- Developing and optimizing Oracle SQL queries and PL/SQL procedures
- Designing Oracle database schemas for enterprise applications
- Tuning Oracle database performance and query execution plans
- Implementing Oracle high-availability and disaster recovery
- Managing Oracle database security and user access

## Workflow

### Step 1: Schema Design
Design Oracle database schema with appropriate data types, constraints, and partitioning strategies.

### Step 2: Query & Procedure Development
Develop optimized SQL queries and PL/SQL procedures with proper error handling.

### Step 3: Performance Tuning
Analyze execution plans, optimize indexes, and tune database parameters for performance.

### Step 4: Administration & Monitoring
Implement backup strategies, monitor performance, and manage security.
