# Firestore Data

## Overview

A skill for effectively designing and managing Firestore databases. Covers NoSQL data modeling, query optimization, real-time listeners, security rules, and scaling strategies for Firebase applications.

## When to Use

- Designing Firestore data models for web and mobile apps
- Optimizing Firestore queries for performance and cost
- Implementing real-time data synchronization
- Writing secure Firestore security rules
- Managing Firestore at scale with indexing and denormalization

## Workflow

### Step 1: Data Modeling
Design collections, documents, and subcollections optimized for query patterns.

### Step 2: Query Design
Structure queries to leverage composite indexes and avoid common performance pitfalls.

### Step 3: Real-time Implementation
Implement real-time listeners with proper lifecycle management and offline support.

### Step 4: Security & Scale
Configure security rules, manage indexes, and plan for data growth.
