# Ralph Wiggum

## Overview

A skill for using Ralph Wiggum (Ralph) task runner for lightweight workflow automation. Covers task definition, scheduling, dependency management, and integration with development workflows for automated task execution.

## When to Use

- Automating repetitive development tasks
- Creating task dependencies and execution chains
- Scheduling periodic maintenance tasks
- Building custom development workflows
- Integrating task execution with project tooling

## Workflow

### Step 1: Task Definition
Define tasks with clear commands, inputs, and expected outputs.

### Step 2: Dependency Mapping
Map task dependencies and execution order for complex workflows.

### Step 3: Workflow Configuration
Configure task execution parameters, schedules, and error handling.

### Step 4: Execution & Monitoring
Execute task workflows, monitor progress, and handle failures.
