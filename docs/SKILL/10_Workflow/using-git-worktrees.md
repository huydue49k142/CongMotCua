# Using Git Worktrees

## Overview

A skill for leveraging Git worktrees to work on multiple branches simultaneously without switching contexts. Covers worktree creation, management, and integration with development workflows for parallel task execution and efficient review processes.

## When to Use

- Working on multiple features or fixes simultaneously
- Running different branches in separate working directories
- Reviewing pull requests without affecting your current branch
- Isolating experimental changes from stable work
- Building multiple versions of a project concurrently

## Workflow

### Step 1: Worktree Creation
Create new worktrees for each branch or feature you need to work on.

### Step 2: Parallel Development
Work on each branch independently in its own directory without context switching.

### Step 3: Worktree Management
Manage pruning, cleanup, and synchronization across worktrees.

### Step 4: Integration
Merge or rebase branches and clean up worktrees after completion.
