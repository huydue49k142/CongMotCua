# Review Team

## Overview

A skill for managing team-based code review processes. Automates reviewer assignment based on expertise and availability, aggregates feedback, tracks review progress, and ensures consistent quality standards across the team.

## When to Use

- Automating code review assignment across team members
- Ensuring balanced review workload distribution
- Tracking review progress and response times
- Aggregating review feedback for actionable improvements
- Enforcing code review policies and SLAs

## Workflow

### Step 1: Review Request
Submit code changes for review with context, related tickets, and review requirements.

### Step 2: Reviewer Assignment
Automatically assign reviewers based on file ownership, expertise, and current workload.

### Step 3: Review Execution
Reviewers provide feedback through structured comments and approval workflows.

### Step 4: Feedback Aggregation
Collect, categorize, and present aggregated feedback with action items and trends.
