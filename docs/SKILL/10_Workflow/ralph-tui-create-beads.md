# Ralph TUI Create Beads

## Overview

A skill for creating and managing bead-based task structures in Ralph TUI. Beads provide a visual, hierarchical way to organize tasks, sub-tasks, and project milestones in a terminal user interface.

## When to Use

- Creating structured task hierarchies for projects
- Breaking down complex tasks into manageable beads
- Organizing project milestones and deliverables
- Tracking progress with visual bead structures
- Managing workflow dependencies and sequences

## Workflow

### Step 1: Task Analysis
Break down the project or task into structured components and dependencies.

### Step 2: Bead Creation
Create beads for each task component with appropriate hierarchy and metadata.

### Step 3: Organization
Arrange beads in sequence with dependencies, priorities, and estimated effort.

### Step 4: Progress Tracking
Update bead status as work progresses and review the task structure.
