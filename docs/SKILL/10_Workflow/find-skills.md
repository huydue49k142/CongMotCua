# Find Skills

## Overview

A skill for discovering and evaluating AI agent skills from various sources including GitHub repositories, skill registries, and community collections. Helps identify the most relevant and high-quality skills for specific use cases.

## When to Use

- Searching for existing skills to solve specific problems
- Evaluating skill quality and relevance before adoption
- Discovering community-maintained skill collections
- Comparing multiple skills for the same use case
- Building a curated skill library for your team

## Workflow

### Step 1: Define Requirements
Identify the specific capabilities needed and constraints for the skill.

### Step 2: Search Sources
Search across skill registries, GitHub repositories, and community collections.

### Step 3: Evaluate Candidates
Assess each skill for quality, maintenance status, documentation, and compatibility.

### Step 4: Select & Integrate
Choose the best skill and integrate it into your agent configuration.
