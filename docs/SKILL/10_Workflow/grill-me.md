# Grill Me

## Overview

A skill for facilitating thorough code reviews and constructive technical feedback sessions. Uses a structured questioning approach to identify potential issues, evaluate design decisions, and improve overall code quality through collaborative discussion.

## When to Use

- Conducting thorough peer code reviews
- Evaluating architectural decisions and trade-offs
- Identifying potential edge cases and failure modes
- Improving code quality through constructive criticism
- Facilitating technical design review sessions

## Workflow

### Step 1: Context Gathering
Review the code or design in context, understanding the requirements and constraints.

### Step 2: Structured Analysis
Apply systematic review criteria covering correctness, performance, security, maintainability, and scalability.

### Step 3: Question Generation
Generate targeted questions about potential issues, unclear decisions, and improvement opportunities.

### Step 4: Discussion & Resolution
Facilitate discussion around the questions and work toward actionable resolutions.
