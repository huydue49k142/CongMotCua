# Ralph TUI PRD

## Overview

A skill for creating and managing Product Requirement Documents (PRDs) within Ralph TUI. Covers structured product requirement definition, feature specification, user story creation, and acceptance criteria documentation.

## When to Use

- Creating structured product requirement documents
- Defining feature specifications and user stories
- Documenting acceptance criteria and edge cases
- Managing product backlog and prioritization
- Collaborating on product requirements with stakeholders

## Workflow

### Step 1: Product Context
Define product vision, target users, and business objectives for the feature or product.

### Step 2: Requirements Definition
Document functional and non-functional requirements with clear acceptance criteria.

### Step 3: Feature Specification
Detail feature behavior, user flows, and technical considerations.

### Step 4: Review & Prioritization
Review requirements with stakeholders and prioritize for development.
