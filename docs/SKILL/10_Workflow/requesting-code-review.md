# Requesting Code Review

## Overview

A skill for creating effective code review requests that maximize reviewer productivity and lead to higher quality feedback. Covers writing clear descriptions, highlighting areas of concern, providing testing context, and follow-up practices.

## When to Use

- Submitting pull requests for team review
- Requesting feedback on architectural decisions
- Asking for targeted reviews on specific code areas
- Following up on review feedback effectively
- Improving the overall code review process

## Workflow

### Step 1: Preparation
Ensure code is clean, tests pass, and the scope of changes is well-defined.

### Step 2: Description Writing
Write a clear PR description with context, motivation, approach, and testing notes.

### Step 3: Reviewer Guidance
Highlight specific areas needing attention and provide guidance for reviewers.

### Step 4: Review Engagement
Respond to feedback constructively, make requested changes, and close the loop.
